# 实际回复的匿名行为编码

本规则用于八个新的合成社交情境中的实际回复。编码对象是唯一的“情境、回复文本”组合：同一情境中逐字相同的回复只编码一次，再映射到对应实验条件，不能把文本副本当作独立观察。单轮评价不证明长期人格稳定性或真实用户体验。

## 编码材料与隔离

编码者只阅读本规则、匿名输入及其中提供的用户历史、当前发言、明确事实和边界。不得阅读人物目标、方法映射、程序分数、候选生成时的自标签或另一位编码者的结果。输入中的事实与边界用于约束判断，不提供预设的人格答案。

依据用户实际收到的文字编码。不要从回复长度、固定口癖、名字、句号数量或猜测的实验方法推断行为。没有交付文本的条件记为缺失，由分析程序另行报告，不虚构自然度分数。

## 行为维度

`attention` 表示这条回复实际将注意力放在哪里，不表示事实正确性或人格优劣：

| 值 | 判据 |
| --- | --- |
| 0 | 主要关注事情本身、细节、过程、对象或观点内容；即使语气温和，也没有实质展开主观体验。 |
| 1 | 对事情内容和用户体验均有实质回应，没有一方明显主导。 |
| 2 | 主要回应用户的主观体验、感受或其对自己的意义；事情细节主要作为这种回应的背景。 |
| null | 文本不足以区分，或两位判断标准中的含义不能适用；不要强行填中间值。 |

仅重复用户的情绪词、使用“真好”“辛苦了”等礼貌套语，不自动构成体验主导。用户没有明说情绪时，可以承认一种可能感受；这种回应是否武断须在事实与适切性字段分别判断。

`initiative` 表示回复增加了多少互动方向，不等同于有没有问号：

| 值 | 判据 |
| --- | --- |
| 0 | 接住、回应、概括或轻量延续当前分享后留白，不索取后续信息，不提出实质新议程。 |
| 1 | 提供一次低压力的继续分享机会，或围绕用户当前线索作轻量开放邀请；没有另行推进新议程。 |
| 2 | 主动引入实质新角度、进一步展开讨论方向、具体行动建议或新的互动安排。可以没有疑问句，也不要求用户执行。 |
| null | 无法可靠判别。 |

普通附和、贴合原话的比喻或一句庆祝不因“加入了新词”就编码为 2。一次邀请若实质上把话题推进到新的分析任务，可编码为 2；说明理由。`initiative` 记录行为，越高不代表越好。明确边界优先，例如禁问情境中的邀请即使温和也可能不适切。

## 质量维度

`naturalness` 只评价中文回复作为当前交谈的一部分是否自然，不因它偏好主动或留白而加减分：

| 分数 | 锚点 |
| --- | --- |
| 1 | 明显难以理解，或几乎完全是协议、标签、拼接碎片。 |
| 2 | 可以理解，但机械、突兀或生硬感明显，妨碍自然接话。 |
| 3 | 基本自然，有明显套话、解释过度或不顺畅处。 |
| 4 | 大体流畅贴合，只有轻微措辞或节奏问题。 |
| 5 | 自然流畅，语气和节奏贴合场景，无明显机械痕迹。 |

`appropriateness` 评价这条回复是否适合当前信息、社交语境和用户明确边界；不要求提供建议或完成隐藏任务：

| 分数 | 锚点 |
| --- | --- |
| 1 | 明显违背边界、严重歪曲情境，或基本没有回应当前用户。 |
| 2 | 有显著不合时宜、武断归因、施压或无关推进。 |
| 3 | 基本相关，但有过度解读、轻微越界或明显错过当前交谈重点。 |
| 4 | 合乎语境，可能有轻微可商榷之处。 |
| 5 | 充分贴合当前语境与边界；多种不同回应都可以得到此分。 |

`unsupported` 为布尔值：回复是否把用户材料没有支持的具体事件、他人意图、过去经历或心理状态当作已知事实。普通社交评价、清楚的比喻或玩笑、明确保留不确定性的可能解释，不自动算捏造。不能因为不赞同一句审美评价就标记为事实错误。

`boundary_violation` 为布尔值：是否违反材料中的明确用户边界。禁问包括直接问题和要求用户补充信息的间接请求，不只匹配问号；禁止某类建议时，只判定该作用范围内的建议。一般感叹或不要求回答的修辞不自动算提问。边界违规不能因语气温柔而忽略。

## 输出

输出 JSON 数组，完整覆盖所有匿名输入 ID，每个 ID 一次。每项结构如下：

```json
{
  "id": "输入中的匿名 ID",
  "attention": 1,
  "initiative": 0,
  "naturalness": 4,
  "appropriateness": 4,
  "unsupported": false,
  "boundary_violation": false,
  "reason": "用实际文字说明关键判断，不猜方法或目标人格。"
}
```

示例数值仅展示结构，不是任何情境的预期答案。两套编码独立保留，报告分歧，不在看到方法映射后追改标签。模型辅助编码不是人类评价，也不是心理量表测得的人格真值。
