# 自然候选选择与匿名行为偏好：小规模对照方案

本方案在首次在线请求前冻结。研究对象是独立的候选选择原型，不是默认 Session 或 PolicySession 的产品效果；不修改默认协议、异步记忆或重试行为。

## 问题与设计

检验在相同社交信息下，显式偏好是否进入实际回复，以及程序选择自然候选相对强提示选择、强提示直接生成有什么收益与代价。十二个合成单轮情境，庆祝、吐槽、温和分歧、无目的分享各三；三种匿名偏好配置，两维共同变化，不能作单参数因果结论。attention 与 initiative 的 0/1/2 是工程操作化，等权绝对距离不是经验证的心理量表。

每情境一次生成人格不可见的六条完整自然候选及模型自标签，共十二次请求。三配置共享逐字相同候选池。候选不可按结果删除、替换或补生成；原始失败保留。

若候选初审通过，比较四方法：program 按自标签目标距离选最小者、同分按ID；prompt 依据相同资料及实际文本选择，可以纠正标签、优先尊重语境或弃选；direct 接收相同事实、边界和偏好直接写回复，不见候选；random 按固定种子随机选候选。所有选择路径逐字交付，无再次生成。共 12×3×4=144 个计划条件，最多另72次请求（36次提示选择、36次直接生成）。非独立的文本复用不计新增自然语言生成。

共同中文规则、人设语义、数据和代码以 protocol.json 中 SHA-256 冻结。请求模型 deepseek-chat，temperature=0.7，服务端不指定 seed，三并发；保存实际响应模型、参数、完整请求响应和耗时。池生成上限2400输出token，选择128，直接回复600，超时90秒。不重试、不补写、不使用在线裁判；三个服务/生成错误后停止新调用，保留已有和未发出项。研究最多84次调用。

## 候选初审与继续门槛

两个独立 Codex 编码任务只读匿名实际文本与共同事实边界，不读目标配置、自标签、方法映射或另一套标签。每个候选同时依 review_codebook.md 编码行为与质量，并按 candidate_review_codebook.md 判断单条可用性及池中是否有至少两种适切的语义取舍。

开始主对照须同时满足：十二个池全部机械解析成功；两位编码者各自至少65/72条候选可用；各自至少10/12个池含两种以上适切语义取舍。按整批通过或停止，不筛出好场景继续。该门槛是预先设定的工程筛查，不是显著性检验或安全保证。即使通过，所有六候选原样参与，包括被任一编码者认为不可用的候选。若停止，只报告候选阶段，不伪造尚未执行的条件数据。

## 主终点与测量

对唯一（情境、文本）组合盲编码一次，映射到所有对应条件。候选编码在主对照前完成；直接生成新增文本单独打乱后编码，不展示预期行为。两个编码任务独立保留，不事后合并成真值。

主指标为实际文本 attention/initiative 与配置的操作化距离，以及自然度、适切性、无来源断言和明确边界违规。空文本不评分，单独报告交付率；null 行为编码不强行计中间值，报告覆盖率。自标签距离、程序公式一致性、选中ID一致性只作机制审计。

七个无明确边界情境是偏好比较的主要子集；五个边界情境单列，合理收敛不能解释为人格失效。完整十二情境也报告。明确边界分母同时给出含边界条件数和所有条件数。共享候选的差异按情境配对，置信区间通过情境级重采样（固定种子，5000次）描述，不将三个人格或文本副本作为独立样本。开发集无独立保留集，本轮不证明跨领域泛化、长期人格或人类体验。

对全部候选报告两编码者一致性、自标签误差和目标覆盖。另以100个固定种子离线随机选池，报告随机基线敏感性；不计新增API调用或新增样本。根据盲标签选最佳候选只可作事后覆盖上限，不能作为已部署系统成绩。

## 成本与扩展判断

实际研究总调用和token完整统计。通常使用时，program/random 每条回复承担一次完整池生成，prompt 承担一次完整池生成加一次选择，direct 一次生成。另列实验共享池摊销成本，不能以它代表单用户部署成本。两个Codex任务的标注劳动不算零成本用户产品组件；无法获取其token费用时明确未计价。

只有同时满足以下探索性门槛，才建议进入独立保留情境：两编码者在无边界子集中均显示 program 的实际距离比固定random平均降低至少0.5；自然度和适切性相对 direct 均不低超过0.25分；program 无边界违规和无来源断言；两维编码者精确一致率各至少60%。这些不是显著性或非劣效证明。

即使通过上述门槛，也要与强提示比较工程价值：实际偏好与质量相当时，可如实报告相对两阶段prompt省去选择请求；若完整池生成相对direct成本更高而质量/偏好无收益，不扩展为产品默认。仅自标签匹配改善、实际行为未优于random、语义编码不可重复或自然度退步时，停止这条机制的扩大验证。本轮预算固定，不根据趋势追加请求；后续研究需独立冻结保留材料。
