# 框架修订的定向验证

本组验证关注记忆原话保留、用户指定答案格式和流式交付一致性。它使用独立新会话与合成任务，不改写[原研究](../followup_2026_11_05/paper.md)的结果。

## 条件

方案在请求前保存在 [protocol.json](./protocol.json)。默认 `text` 关闭额外核查、格式回退与模型请求重试；请求模型为 deepseek-chat，实际响应均为 deepseek-flash。

- 格式任务：沿用八道事实题，中性和蓝鱼两套表达配置，每格两次，共 32 条输出。使用原研究公开的小数点规范化规则进行严格结论评分。
- 真实记忆：四次独立重复，每次三轮真实训练、一次两阶段模型固化，以及载入实际记忆与空白记忆各一个新会话探针，共 20 条输出。
- 跨 Store 导入保留完整 `evidence_quotes`，并核对引用随账本重建保留；原话是历史用户陈述，当前明确更正优先。
- 历史流重放：将原研究中全部 400 条框架生成流的原始文本增量送入修订后的解析器，比较回调交付和最终文本。

## 结果

| 指标 | 结果 |
| --- | ---: |
| 中性配置的指定结论严格匹配 | 13/16 |
| 蓝鱼配置的指定结论严格匹配 | 12/16 |
| 实际固化记忆载入后的双数字严格召回 | 4/4 |
| 空白记忆对照回答未知 | 4/4 |
| 引用经真实账本重建后保持一致 | 4/4 |
| 全部在线输出本地协议有效 | 50/52 |
| 在线回调与落账文本一致 | 52/52 |
| 历史框架生成流重放后交付一致 | 400/400 |

实际归档 36 个单元、52 条对话输出和 60 次模型调用，执行错误为零。结构仍有两例无效，不能据此宣称输出协议已普遍可靠。新记忆探针使用原研究相同的17/3分钟偏好；四次成功只支持该条件下的端到端验证，不能外推为所有记忆都完整保留。

这是修订后的定向验证，不是同期随机化的新旧版本优越性实验。研究任务、重复数和服务状态有限，也没有独立评价全部回答断言。`intervention` 的指令已细化，但本组没有重新估计其建议频率的单调性。
