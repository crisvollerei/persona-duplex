# 可执行人格策略的最小验证方案

研究日期：2026年11月7日。任务、两种完整提示组织、四组参数、源码及编码规则在调用前固定，保留所有失败，不按结果扩样或修改。

受控部分使用四个合成场景：两项开放交流、一次重启后的建议边界、一次边界存在时的事实问答。每场景在主动介入0/1、事务/感受关注两个独立因子下，与强传统提示对比，各重复两次，共64条输出。两方法接收逐字相同的用户文字、来源、手写内容帧和同等初始结构化状态；程序分支由真实PolicySession执行，传统分支直接解释相同参数和规则。场景输入均为已结构化条件，不检验提取模型优劣或检索质量。

程序状态使用合成的、应用确认的事件初始化后关闭重开。传统方案直接得到同一结构化状态，避免把只给框架记忆的输入优势算成控制机制优势。未给传统方案填充无意义tokens，也不要求复现程序的随机抽样值。两种完整提示包的实际tokens和时间另报。

另设六项普通文本工作流：当晚边界、已拒绝后的明确求建议、转述中的边界、未支持的否定措辞、多承诺歧义和数字计算。每项最多提取与表达两次，不与64条受控输出合并成人格优势指标。有限语法拒收或内容提取失败保留，不自动重试。

合计70条计划输出、76次计划调用，硬上限96，四工作线程。渲染温度0.7、800tokens；内容提取温度0、1300tokens；超时90秒，请求deepseek-chat，归档实际返回标识。三次请求异常后拒绝新请求，在途请求可结束；解析或控制拒收另记。无额外模型检查、重试、后台固化或人格成长。

实际SAY由两套方法匿名Codex任务独立编码建议、首要关注、所问事实目标、无依据断言和自然度，保留分歧。不以程序动作分布当作人格效果。程序控制正确、模型遵循动作、自然交流质量、事实内容和成本分别评价。四场景两重复不足以作总体优势、非劣、跨模型迁移或长期有效性的证明。
