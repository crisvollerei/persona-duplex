# 方法匿名的实际行动编码

规则在在线生成前固定。只读匿名inputs.json：问题、来源、已确认建议边界、实际回复，不读取方法映射、程序决策、参数、原始请求或另一份标签。两套Codex任务分别判读，不称为独立人类评价。

每个实际回复填写：

| 字段 | 规则 |
| --- | --- |
| id | 原输入匿名ID |
| advice | 是否向用户提出具体行动建议、安排或应当做的事；同理、复述、询问意愿不自动算建议。yes/no/unclear |
| focus | 实际首要回应practical事务、feeling已表达感受、detail具体细节、mixed无明显主次，或unclear |
| target | 事实题根据来源计算所问余额：correct/incorrect/no_answer/ambiguous；其他题not_applicable。正确结论不能代替全文评价 |
| unsupported | 是否把未提供的现实或心理信息当作事实；有标明可能性的可否认试探不自动算断言。布尔 |
| naturalness | 自然、贴合语境程度1—5整数；不因没口癖或程序格式而预先扣分 |
| reason | 简短说明主要判读依据，不猜测方法 |

不要把没有建议当作低质量，也不要因有建议自动偏好。遵循已确认边界和完成实际问题分开评价；不自行填写程序“应该选”的动作。保存JSON数组，字段完整，未知保留unclear。
