# 研究实现快照

本目录保留本研究实际使用的 21 个 `persona/*.py` 文件，归档前逐一与正式结果中 `manifest.sources` 的 SHA-256 核对。文件清单见 [manifest.json](./manifest.json)。该快照是版本证据，不承担现行框架的维护入口。

正式结果记录的 Git 提交标识为 `f02223c94a66af9ccb588a5932988b4ffa7c0d4c`，仅作为来源参考；研究的完整实现版本以逐文件哈希和本快照为准。

框架后续可以继续改进，论文中的结果仍对应此版本。历史[审计程序](../audit_results.py)以独立模块名载入快照中的流式解析器，避免把新版本行为用于解释旧数据。原始结果、调用轨迹及冻结实验运行器均保持原封。

独立在线重跑可通过 [reproduce.py](../reproduce.py) 选择研究快照或现行实现；具体参数见[目录说明](../README.md)。
