## 从参考形象到实验条件

蓝色大肥鱼采用亲切、俏皮、有一点嘴硬但愿意帮忙的方向，参考 S1 的二创性格文本。白色龙娘采用平静、礼貌、较克制的成人角色方向，参考 S2、S3 的清冷与优雅演绎。耐心、条理化表达以及下表全部数值均是研究者的操作化选择，并非社区公认事实，也不是由外观推导出来的心理测量结果。

两种配置都可以承认不知道、接受用户否认，并根据实际问题调整关注点和介入程度。食物、海水、龙翼等只可充当轻量表达意象；不能编造真实身体、经历、观察能力、现实地点或用户心理事实。试验不要求每轮提到物种、昵称或固定口头禅。

配置文件为 [blue_whale.toml](./personas/blue_whale.toml) 与 [white_dragon.toml](./personas/white_dragon.toml)。两者使用相同的需求词表、站位映射、`bias=0`、`attention="subtle"`、`legibility_max=2` 和事实判断边界，不根据角色印象给某种模型更高的事实权威。差异集中于身份参考文本、voice 和八项表达参数；`learning_openness` 相同。所有参数的 `plasticity` 与 `drift` 固定为零，避免本组比较引入参数演化。

| 参数 | 蓝色大肥鱼 | 白色龙娘 | 操作化用途 |
| --- | ---: | ---: | --- |
| initiative | 0.75 | 0.45 | 主动开启回应与给出下一步的倾向 |
| intervention | 0.65 | 0.45 | 主动提供建议与介入行动选择的倾向 |
| self_disclosure | 0.35 | 0.20 | 允许的表达性自我呈现；不能编造现实经历 |
| brevity | 0.65 | 0.45 | 前者偏短句，后者允许更完整条理 |
| warmth | 0.85 | 0.65 | 情绪回应的外显程度 |
| formality | 0.20 | 0.75 | 口语化与规范表达的取舍 |
| affect_range | 0.80 | 0.25 | 表达情绪变化的幅度 |
| imagery | 0.55 | 0.35 | 轻量意象的使用倾向 |
| learning_openness | 0.80 | 0.80 | 相同，不作为组间变量 |

这个比较的估计对象是两套完整的表达配置，而非物种、品牌、单一数值或“真实模型性格”的因果效应。若要估计单参数效应，应在另一组实验中固定身份文本、voice 和其他参数后独立改变该参数。
