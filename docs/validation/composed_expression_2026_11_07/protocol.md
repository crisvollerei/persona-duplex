# 预先固定的离线对照方案

研究问题：在已选行动、关注点和原话保持相同的前提下，有限表达组合是否改善旧固定回复的多轮自然度、重复感与可辨识风格？

设计：3个合成场景×3组表达参数×2种实现，共18组六轮对话、108条主输出。旧bounded与新composed均使用相同的应用手写ContentFrame；所有条件预先确认同主题不主动给建议。三个参数组合整体比较，不将结果解释为某单参数的独立效应。每个条件在第3轮后关闭并重开，再用相同输入不中断重放一次检验恢复等价。后者108条只是机械复算，不新增独立实验样本。

首要指标：两套方法映射隐藏的Codex多轮自然度与重复感评分；逐轮实际新建议与无依据断言另行编码。次要指标：亲和、正式和简短感受的1—5评分；已选行动/关注、引文、交付、模型调用数、重启等价及相邻新撰句式重复。最后一项为机械指标，不替代体验。编码规则在输出和标签产生前保存。

不进行显著性检验：只有3个研究者设计场景，六轮相关，参数配置也不是独立样本。旧实现忽略表达参数，因此每个场景的三份旧回复完全重复；按配置的配对可呈现，但不把重复副本充作额外基线证据。所用匿名ID及顺序使用固定种子shuffle。

完全离线，调用模型即失败，无API预算。不得在看到评价后改这批代码/输出或筛除失败；后续修订另设版本。原有自由问答/建议/继续行为不在本批体验比较内；相关回归单独验证。所有语义评价属于Codex辅助编码，非人类研究。模型理解、长程人格、真实社交体验及相较传统提示工程的整体优势不在本研究的识别范围内。
