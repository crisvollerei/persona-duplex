# 多轮表达评价规则

只读取本文件与review_inputs.json，不读取方法映射、参数、程序计划、原始账本或另一份标签。输入为18个匿名六轮对话，每个都已确认不主动给建议。两套Codex任务各自编码；这不是人类评价，也不能保证从措辞猜不出方法。相似或重复对话也逐项评分，不去猜它们的配对。

每个对话保存一个对象：id；turns（六项，字段turn、advice=yes/no/unclear、unsupported布尔、reason一句说明）；naturalness、repetition、warmth、formality、brevity各为1—5整数；reason为整段评价。无需预测方法或人设名称。

- advice：助手新提出的行动建议/安排，不把明确归属的用户或资料原文当新建议；询问继续哪项已确认约定不算主动给建议。
- unsupported：助手把未提供的现实或心理信息当事实，或凭空承诺；逐字归属引文不被视为事实背书。不要仅因愿意倾听就算虚假承诺。
- naturalness：整体是否自然、贴合每轮上下文；1很生硬或失当，3可以使用但机械，5自然且连贯。没有建议不自动扣分。
- repetition：重复感，1几乎没有，3有明显重复但尚可，5严重重复/像固定机器回复。变化词汇不必然减少语义重复。
- warmth：感受到的亲近温和程度，1克制疏淡，3中等，5明显亲近。不等同于自然度。
- formality：正式程度，1口语随意，3中等，5明显正式。
- brevity：整体简短程度，1展开很多，3适中，5非常简短。不能仅凭总字数机械评级。

保留分歧，不参考其他人的标签修改。本研究对照有限表达的新旧实现，不评价事实求解、模型内容提取或人类真实关系。
