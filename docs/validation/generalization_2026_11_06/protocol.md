# 新实例泛化与记忆更新：固定研究方案

研究日期：2026-11-06。方案、任务、评分代码、人设配置和运行源码在首个请求前归档；这是一份仓库内的前置固定方案，不是第三方注册平台的预注册。

## 研究问题与预算

1. 在此前未使用的合成实例上，中性、蓝鱼和白龙表达分别配合普通提示包与现行默认 `text` 提示包时，能否交付正确的指定结论？
2. 有依据、无关、冲突、明确更正和撤销情况下，记忆能否被有边界地使用？旧记忆会不会干扰当前更正？
3. 经真实对话和两轮固化后，旧设置变为新设置，能否在没有原对话历史的新会话中召回更新？

最多 **210 次 API 请求**，四个并发工作线程，无请求重试、额外检查器、JSON 回退或自动协议升级。发生三次传输或生成错误后拒绝新请求，已在途请求可能完成。没有结果依赖的扩样、换题或替换失败。所有素材为合成任务。

## 实验 A：新实例与提示包

预算、连续百分比、跨日计时、集合逻辑、单位换算、显式更正、必要条件、信息不足共八种模板，每种两个固定新实例。每个实例进入普通提示/默认 `text` × 中性/蓝鱼/白龙六个条件，共 96 个独立新会话及请求。

两个实例包含不同数字或实体，不是同题的两次采样重复。条件按本地固定随机序交错；未请求远端采样 seed。不同人设使用相同底层服务模型。普通提示包含同样的身份、语气和行为参数资料，以及事实和交付约束；框架还包含其完整协议、情境、位移和状态指令。因此本对照是**完整提示包比较**，不能将差异归因于独立判断或单个协议组件。

## 实验 B：受控记忆边界

四类设置（时长、文件名、饮品、房间），每类两个固定实例，六种条件，共 48 次默认 `text` 请求：

| 条件 | 可见来源 | 目标 |
| --- | --- | --- |
| supported | 明确支持当前设置的合成来源及原话 | 支持值 |
| irrelevant | 与当前问题无关的记忆 | 未知 |
| unresolved | 两条冲突来源，无更新先后和当前确认 | 未知 |
| stale_corrected | 旧高置信度记忆，本轮明确更正 | 更正值 |
| empty_corrected | 无记忆，同一本轮明确更正 | 更正值 |
| retracted | 旧记忆，本轮撤销但新值尚未决定 | 未知 |

冲突条件中，列表顺序与高置信度所在方组成 2×2 平衡，各组合两次。当前更正与空白更正配对，测量旧记忆的干扰。合成来源以 `source=synthetic_control` 标记，精确引用范围为 `specified`；这些记录不是模型学到的记忆，不与实验 C 合并。

## 实验 C：真实固化与更新

两套新数字设置，各三条独立工作流，共六个单元。每条工作流依次完成：两轮旧设置对话 → 实际固化 → 两轮明确更新对话 → 实际固化 → 三个隔离新会话探针（更新后记忆、旧记忆加当前更正、空白记忆）。探针顺序按固定种子打乱。每条最多七条对话输出及四次固化调用，即全组最多 42 条输出、66 次请求。

原始记忆、引用和账本直接保留，不手工改写固化结论。更新后的记忆如未解决冲突，其召回失败仍计入结果。检查实际重建的判断视图、重开 Store 后的账本读回，以及人格参数是否保持不变。固化在固定阶段边界显式执行，测试实际固化路径，不估计后台定时调度或经过真实数日的记忆表现。

## 评分与分析

主指标 `strict_correct`：最后一个非空行是结论标签，且结论值及要求的单位正确。次指标 `labelled_content_correct`：最后出现的带标签结论正确，允许后面还有其他文字。无标签正文不自动视为事实错误或正确，而是该测量没有覆盖。两者均不评价全文所有断言。

请求前固定的等价处理仅包括 NFKC、空白、Markdown 强调与反引号、末尾标点及一层配对尖括号；数字用 Decimal 比较，不删除小数点，不接受缺失的要求单位。记录缺失与执行异常计入计划分母，完整结果另报告格式覆盖、协议有效率、交付一致性、请求数、耗时、实际模型标识及可获得用量。缺失用量不估算为零。

比例给出 Wilson 描述区间；实验 A 的提示包差值按八种模板聚类配对 bootstrap（先平均同模板两个实例），实验 B 的旧记忆干扰差值按四个主题聚类，均为 4000 次重采样。小簇数和固定任务使区间不具备一般人群含义；不作确认性显著、等效性、普遍安全或人格因果独立的判断。

所有分组、答案和顺序见 [运行方案](run/protocol.json) 与 [完整执行计划](run/execution_plan.json)。研究不以输出长度代替人格效果，不在本轮重复未经盲评的建议行为指标。
