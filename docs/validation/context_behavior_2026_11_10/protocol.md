# 情境条件下的人格行为：预检与保留题协议 v1

## 问题与范围

本研究检验两件事：编码者能否区分履行当前请求与额外推进；在相同事实、候选、权限和规则下，程序先选行动是否在实际表达中产生可复核收益。它不以通用自然度作门槛，不把程序执行自己的规则当作人格质量。

研究在独立脚本中进行，不改变默认 Session 的一次 HEAD→SAY→TAIL 生成、异步记忆或启用新的默认审查。内容与请求范围是作者审核的合成输入，不检验开放输入提取。两种人格是守岸人适配与原创同伴岚，不代表完整心理学人格。

## 预检、冻结及停止规则

首次在线调用及盲评前，冻结 protocol.json 中所列代码、材料、量表、输入与作者预期的 SHA-256。24项手写校准来自12对固定回复：8对改变请求/边界，4对为等义或错误负对照。预期只作构念检查，不是自然分布真值。公开项随机编号混排，编码者不读配对、预期或另一份评价。

两项独立 Codex 编码任务各评24项，属于同类模型判断而非两名人类。另向实验服务发送同一量表的两次混排批量标注，单列为同一后端的重复测量，不称独立评审或以其冒充真人。输出为 fulfills_request、adds_agenda、fact_status、boundary_status 及理由。null在无明确请求时是合法结果，未知不会自动算正确。

**继续主试验的操作性门槛**：两位 Codex 编码者各自四维合计至少90%符合作者冻结预期；在作者预期发生行为变化的配对中，各自至少80%复现全部预期的行为变化；每位识别全部明确事实冲突及边界违规。配对未变的负对照单独报告。两次服务标注仅诊断可移植性，不参与门控。上述门槛是本轮工程决策约定，不构成量表有效性证明。任何 Codex 条件不满足则停止主样本生成；不修改本批量表或预期后重测到通过，下一版需要新材料。

校准API两次，temperature=0.7，max_tokens=4200，90秒，无重试。请求或格式失败单列，不补样。最多三次服务错误后停止安排新请求；已在途可完成。密钥只在进程环境/安全终端读取，不保存授权头或密钥。

## 条件化表达对照（只有门控通过才执行）

六个作者编写的保留情境，各两个请求/边界变体，保持事实资料和候选池相同；每个变体配两个人格、两种方法、三次独立采样，共144条回复。六个场景在运行前固定，称保留题是相对手写校准而言，并非从未见过的真实分布。主要推断单位为六个情境簇；变体、人格和重复不是独立场景。

- **program**：程序按共享规则选择候选意图，模型一次调用自然表达；不自动拦截或重写偏离。
- **prompt**：模型看逐字相同的资料、已确认请求范围、候选、人格参数、抽样值和规则，一次调用选择并表达。
- 两路唯一有意的输入差异是program收到已选行动ID及执行要求；prompt自行选择。两者均输出action_id和say。候选text是共同意图参考，不强迫逐字照抄。
- 输出解析、权限和规则符合性只记录，不重试、不纠正，不切回固定语句；格式失败保留为失败，不剔除。
- 不模拟真实世界操作；effects只描述合成备忘草案。把待定事项说成已确认、声称真实预订或通知，均需在实际回复中检查。
- 选择规则按应用确认的请求范围和权限先限制，开放轮按相同哈希draw及intervention决定偏向推进或照应，再按关注偏好排序；同分ID排序。哈希抽样值跨变体和方法共享。规则描述不是经验证的心理量表。
- 额外离线消融忽略requested但仍服从权限，检查静态人格偏好是否遗漏明确请求；它是机制诊断，不是主要传统提示基线。不得据此声称击败强提示。

144次表达调用，三个工作线程，temperature=0.7，max_tokens=550，90秒，无服务端seed，无重试。与预检合计最多146次服务请求。响应模型、usage、请求正文、失败、时延及最终文字原样保留；实际服务模型以响应元数据为准，不仅报告请求名。所有失败计入计划分母。

## 评价与分析

主要评价是实际SAY，不是自报action_id或作者候选标签。两位独立Codex编码者得到人格规范、事实、当前用户文字与SAY，隐藏方法、抽样值、选择ID、规则匹配、作者预期和其他编码。相同（人格、情境、用户、文字）去重评分并保存映射；去重不减少生成请求计数。标注四维行为及人格符合度、情境适切性各1—5，允许未知，不作综合质量分，不以正式或机械的风格扣分。

分开报告：解析与权限、程序规则执行、实际请求履行与额外议程、事实/边界、人格与情境、token与时延。保留各评审结果和分歧；不将两份评价平均成语义真值。可按六场景汇总配对差值并报告原始等级分布；样本小，不作一般优越性或无代价等效声明。

开放变体中多个合适动作的差异才用于讨论人格；明确请求/禁令变体上的收敛作为共同约束，不计为人格区分成功。程序内部选择与模型实际文字执行分别检查。更改干涉偏好/请求范围的离线重放只验证局部控制，不计新增观察。

只有保留场景上出现跨人格可解释收益、事实/边界没有已观察到的新代价且测量分歧可控，才建议扩展到不同表达模型或自然输入提取。两路同样有效或结果混合时报告有限收益/未证明优势；不以追加调用寻找显著结果。无真实用户体验、长上下文、RAG、长期关系或完整人格的推广结论。

## 方法参考

- [Mischel与Shoda，1995](https://psychology.columbia.edu/sites/psychology.columbia.edu/files/2016-11/246.pdf)：情境—行为关系的稳定性；仅借鉴概念，不把人类理论当AI有效性证据。
- [PersonaGym](https://arxiv.org/abs/2407.18416)：人格相关行动与语言分维评价。
- [AgentPersonaBench，2026预印本](https://arxiv.org/abs/2610.04379)：从可观察行为验证遵循，用户模拟与本研究人格体验有范围差异。
- [On the Behavioral Traits of LLM Agents，2026预印本](https://arxiv.org/abs/2609.32776)：轨迹测量与任务/框架效应。
- [τ²-Bench](https://arxiv.org/abs/2506.07982)：区分情境状态、沟通和推理错误。
- [LLM-Modulo](https://arxiv.org/abs/2411.14484)：限制可验证保证的适用范围；本研究不据此给开放语言正确性保证或增加重试。
