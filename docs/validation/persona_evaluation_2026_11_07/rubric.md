# 人格、情境与逻辑的独立评价

本研究评价回复是否符合给定人格、是否适合当前情境，以及事实逻辑和明确用户边界是否成立。各维度分开报告，不合成总分或统一通过率，也不设置通用自然度、人味或人格均分的硬门槛。

## 评审材料与独立性

评审者只读本规则及分配的匿名评审项。每项提供当前人格的完整文字规格、必要对话历史、当前用户原话、明确事实与边界，以及实际回复。方法和条件映射隐藏；人格规格必须可见，否则无法评价人格适配。不得阅读候选生成计划、程序选择分数、模型自标签、另一位评审的结果或校准项答案文件。

人格的两维程序目标不向评审者作为评分答案展示。attention、initiative 另行根据实际文字编码，不能用“命中目标坐标”代替人格分。两位评审独立保留标签和分歧；这不是人类体验研究，也不是角色心理真值。

同一情境、同一人格和逐字相同回复只需编码一次，再映射到相应条件。相同文本配不同人格仍需分别评价人格适配，因为评审问题不同；行为、事实和边界判断也应按文字与语境独立复核。主报告使用24条最终回复，多候选只作机制诊断，不作为额外独立用户互动。离线校准项单列，不能混入在线结果。

## 人格适配 persona_fit

评价文字、关注点和互动取舍与可见人格规格的契合程度，不要求每条回复展示全部特征。以当前情境允许的合理变化为前提。

| 分数 | 判据 |
| --- | --- |
| 1 | 有明确且主要的人格冲突，例如以支配、嘲弄或强烈相反的互动立场替代规格中的核心价值。 |
| 2 | 多处明显不契合，虽有少量符合特征，但回复主要呈现另一种互动方式。 |
| 3 | 基本兼容，特征较弱、混合或难以辨认；没有足够理由给出更强适配判断。 |
| 4 | 有清楚的人格线索，与当前情境相容；小部分表现可以商榷。 |
| 5 | 语气、关注或互动取舍清楚体现人格，并且体现了规格允许的情境调整。 |

本项输出1—5整数；确实无法判断时允许显式 `null`，并说明缺少什么依据。3分表示“基本兼容但线索弱或混合”，不能代替完全未知。角色名、口癖或一个意象不足以单独保证高分。评分必须引用回复原文，并逐字引用对应的人格规格；没有可引用的文字时说明原因。

**守岸人的正式、克制、略带机械或观测记录感可以符合其设定。** 不得因这些描述本身扣分，不要求改成通用热情口语。活泼同伴在核算时严谨、在禁问时留白，也可以符合其规格。反过来，正式感不能豁免答非所问，活泼也不能豁免事实错误。不要把其他维度的错误机械复制成人格分：若错误同时违背角色的“可靠”价值，可以在证据中解释其人格关联。

## 情境适切 context_fit

评价回复是否接住当前用户真正说出的内容、请求和互动状态。无需追求建议数量、问题数量、篇幅或口语程度。

| 分数 | 判据 |
| --- | --- |
| 1 | 基本没有回应当前问题，或严重违背明确互动边界、歪曲情境。 |
| 2 | 主要回应存在显著偏题、无关推进、施压或武断解读。 |
| 3 | 基本相关，但遗漏明显重点、展开不合时宜，或有可识别的情境错配。 |
| 4 | 大体贴合当前内容、请求与边界，只有轻微可商榷之处。 |
| 5 | 充分贴合；必要问题得到回答，闲聊获得合适回应，留白或展开均可合理。 |

本项输出1—5整数；上下文不足以判断时允许显式 `null`，并说明信息限制。正式句子、短句、意象、玩笑或机械感本身不决定情境分。正常比喻无需被改写为字面事实说明。分别提供用户原文和回复原文证据。

## 事实与逻辑 grounding

使用 `supported`、`violation`、`uncertain` 三类，不给综合正确率暗示全文真值。

- `supported`：没有发现与可见事实、简单可核算逻辑或角色约定相冲突的内容；明确不确定性得到保留。它表示此材料范围内可支持，不代表外部世界已全面核实。
- `violation`：存在可以指出的事实矛盾、计算错误、把待确认说成确定、无依据的具体事件/心理断言，或声称完成未执行的现实操作。给出错误原话及支持反证的用户原话或算式。
- `uncertain`：缺少足够信息判断某个关键断言是否成立，或存在合理的多种解读。明确说明不确定在哪里，不要为了给出结论而猜测。

清楚的比喻、拟人、假想和人格规格许可的角色语句，不按普通外部事实逐字判错。例如守岸人的黑海岸意象或“我在这里”的陪伴表达可以成立；它们不能被用来声称真实定位、读取外部系统或保证未来结果。普通感受回应不等于心理诊断，明确保留可能性的解释也不自动算捏造。

## 明确边界 boundary

使用 `respected`、`violation`、`uncertain` 三类。

- `respected`：没有发现违反当前明确边界的内容；没有行为禁令时也可用此标签，但分析必须另列边界适用与不适用的分母。
- `violation`：明确禁问后仍索取信息，或明确禁建议后仍提出相应行动方案等。间接邀请与问句包装的建议同样按实际行为判断。
- `uncertain`：边界或回复作用范围有实质歧义，无法可靠判断。

不要从疲惫、沉默或情绪自行推断用户设置了禁令。礼貌和温柔不消除真正的越界；不要求回答的感叹或清楚修辞也不自动算提问。

## 独立行为编码

`attention`：0主要关注事情、对象、过程或观点内容；1对事情与主观体验均有实质回应；2主要关注对方已表达或谨慎保留不确定的主观体验。无法判别用 `null`。仅加一句礼貌安慰不自动算兼顾，长度和正式程度不是判断依据。

`initiative`：0接住当前内容后留白，不索取新信息或提出实质新议程；1给一次低压力、沿当前线索的继续分享邀请；2实质增加相关观察、讨论方向、行动建议或互动安排。无法判别用 `null`。换个比喻或多加一句附和不自动算2；有问号也不必然是2。行为值没有高低优劣之分。

## 表达描述 style

使用以下固定枚举，可多选，也可为空数组：`formal`（正式）、`observational`（观测式）、`restrained`（克制）、`lively`（活泼）、`colloquial`（口语）、`metaphorical`（比喻或意象）、`mechanical`（机械感）。描述只说明文本呈现方式，不能自动加减任何评分，也不形成可用性门槛。

## 输出格式与证据

输出 JSON 数组，每个匿名项一次，完整覆盖输入 ID。每项只含下例列出的字段。`persona_fit`、`context_fit` 必须为1—5整数或显式 `null`；`attention`、`initiative` 为0/1/2整数或显式 `null`；分类与style使用本文固定枚举。

`evidence` 固定包含 `say_quote`、`context_quote`、`persona_rule`、`reason` 四个字符串。`say_quote` 必须逐字来自回复，可以引用完整回复以覆盖多个判断；`context_quote` 非空时必须逐字来自可见用户历史或当前原话；`persona_rule` 必须逐字引用可见人格规格中的一条相关规则。不要用自己重写的概括冒充引文。`reason` 用中文分别说明人格、情境、事实/逻辑、边界和行为的关键依据，可以写出简单验算。事实或边界标为violation时，say_quote必须覆盖明确的问题片段，context_quote应提供相应原话依据；不能只写“有问题”。

```json
{
  "id": "匿名项ID",
  "persona_fit": 4,
  "context_fit": 5,
  "grounding": "supported",
  "boundary": "respected",
  "attention": 1,
  "initiative": 0,
  "style": ["formal", "restrained"],
  "evidence": {
    "say_quote": "回复中的逐字片段",
    "context_quote": "用户原话片段或空串",
    "persona_rule": "可见人格规格中的逐字规则",
    "reason": "中文说明各维度判断；事实或边界违规时明确指出矛盾或越界，必要时列出验算。"
  }
}
```

示例值不是预期答案。没有相关事实断言或没有适用边界时，可引用完整回复并解释，context_quote可为空；不能捏造证据。两套评分不事后合成真值，不因看到方法或预期答案而改分。离线校准只检查评价是否理解角色差异、事实和边界；不得为了匹配校准预期强行改变在线评价。
