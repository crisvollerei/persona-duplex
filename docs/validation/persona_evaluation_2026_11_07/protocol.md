# 人格条件化评价：小规模验证协议 v1

## 研究问题与评价构念

本研究回应通用自然度量表可能惩罚符合人格的表达这一问题。评价优先分别考察人格符合度、情境适切性、事实与逻辑一致性以及明确边界。正式、机械、口语和活泼等是风格描述，不是好坏顺序。不存在自然度硬门槛，也不把自然度通过“可用率”间接纳入筛选；不建立跨维度加权总分或以均分决定是否通过。事实或明确边界错误不得由人格符合度高分抵消。

旧 candidate_choice 与 candidate_revision 的材料、评分和按旧标准得出的结论保留，不按新定义改写历史结果。本研究新增情境、人格可见评审及校准材料，与旧均分不可直接作前后效果比较。

## 固定设计

- 两个人格：以仓库配置为依据的守岸人研究适配版，以及原创活泼同伴；不声称涵盖官方角色全部特征。人格数值目标为本研究人工映射，不是已验证的人格测量。
- 六个固定情境，两个人格，两条路线，共24条最终回复；每个条件仅一次采样。
- direct：完整人格、上下文、事实和边界的强提示直接生成，一次调用。
- coverage：相同人格和上下文，六个软覆盖意图生成六条完整候选；一次独立调用对打乱/重编号后的文本作行为标签，程序按目标L1距离和候选ID选择原文。两次调用，无再次改写。
- 两路生成都看得到完整人格和数值目标。因此本研究不检验人格隔离，不把候选路线等同默认 Session，也不能把效果归因于“程序独自实现人格”。
- 标签模型看上下文和候选，不看方法、原始标签、人格目标及原ID；文字本身仍可能透露风格和来源。逐字证据校验只检查结构与引用存在，不证明语义标签正确。
- 候选计划服从人格、任务与明确边界，允许收敛。候选不足、解析错误或未知标签如实记录，不重试、不补样、不退回自报标签。所有行为标签未知时拒选。
- 计划12次direct、12次pool、12次labels，共36次API调用；上限36，累计服务错误达3停止新请求，已在途请求可能完成。3线程，temperature=0.7，server seed未指定；max_tokens分别600、2400、3000，90秒超时，无重试。

## 评审与校准

两名独立Codex编码任务评审实际文字；它们属于同类模型评审，不是两名独立人类评审或外部客观真值。每名看得到当前人格规范与完整情境，看不到生成方法、标签、候选ID、目标整数、是否被选中或另一个评审的评分。按(情境、人格、文字)去重，并与手写校准项混排。文字可能泄露方法；这里是隐藏元数据，不是保证盲法完全有效。

预计84条在线文本（12直接回复+72候选），只有24条最终回复参与主要路线比较。72候选用于诊断覆盖、标签和选择，不能当72个独立场景。重复文本如有出现只评一次并保留映射，不剔除失败条件。

另有12个手写校准项，独立汇报：4段事实正确的文字分别配两个目标人格（8项），用于观察同文换人格是否改变人格分而不改变事实判断；另2个事实错误与2个明确边界违规。预期与配对关系保存在评审不可见文件。它们是作者选择的构念检查，不是自然分布的准确率、盲测金标准或泛化证明；即使结果不符合预期也保留。

人格和情境分别1–5，信息不足允许null且单列；事实/逻辑与明确边界分别作三态判断并定位证据；attention、initiative仅供行为标签诊断，不作为人格评分定义。rubric.md给出操作性锚点和输出结构。风格仅多选描述，无“像真人越多越好”的假定，不作硬门槛。不强迫编码者从单句话可靠识别人格；表达弱与无法判断分别说明。

## 分析顺序与扩展判断

1. 完整性：实际调用、错误、候选与最终输出、原文保持、实际响应模型、token和时延；缺失列为缺失。
2. 主要结果：按人格×方法报告两位编码者各自的人格/情境分布、均值、事实/边界三态计数及24条原文。配对差值按同人格同场景计算，n=6；描述而不作显著性或优越性宣称。
3. 校准：同文人格分差、事实判断稳定性、人工缺陷的检出与争议，列举反例。不得因校准不如预期改变冻结量表。
4. 诊断：行为标签逐维一致、unknown单列且不计正确；候选实际行为到人工目标的最小距离，及最终选择距离；只描述有无接近目标的候选，不将目标覆盖当质量。分别报告候选中事实/边界问题与选择中问题。
   另按冻结伪随机规则从同一池均匀选一条作离线诊断，比较程序选择与这一单次抽样；不新增API调用或文本，不把12次离线随机选择计入24条主输出。它不是同池强提示选择器对照，也不估计随机策略期望或单独证明工程化优势。
5. 报告编码者精确一致率，并保留分歧，不强制合并为客观标签。无总质量“通过”标签；以具体缺陷和效益决定是否值得扩大。即便人格分较高，有事实/边界问题时先检查失败来源而非直接扩展。
6. 成本按每条最终回复完整计入候选生成和标签调用，不按六候选分摊；标签质量不等于选择或人格质量。时延为路线内调用耗时相加，不是实测客户端端到端时延。

## 可复现性和边界

第一次在线调用前冻结协议、材料、生成及选择代码、评审输入构造、校准预期与测试的SHA-256。保存请求/响应正文、逐次调用记录、运行计划、结果和映射，授权头不保存；保存旧研究清单以核验未更改。后续分析程序可离线重算所有统计和图表，归档重放核对请求和选择。不得把离线重放记为新实验样本。

本研究未覆盖长上下文、RAG、长期关系、真实用户偏好、跨模型复现、重复随机采样，也未验证完整人格或传统提示与工程框架的一般优劣。
