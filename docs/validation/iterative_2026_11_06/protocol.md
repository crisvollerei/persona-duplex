# 显式契约、记忆更新与人格行动：分阶段方案

研究日期为2026-11-06。全局任务、金标、执行顺序与请求预算在R0前固定于 [protocol.json](protocol.json) 和 [execution_plan.json](execution_plan.json)。每轮另在发请求前冻结实现版本、运行器及轮次方案；这是仓库内前置固定，不是第三方平台注册。

## 问题与识别边界

1. 无歧义请求下旧版仍有哪些交付问题？显式回答契约带来的作用来自编译提示，还是只是给已有输出增加机械检查？
2. 记忆更正是否错误地受模型置信度支配？合法更正、撤销、临时例外、转述和未确认设想能否保持来源及持久状态边界？
3. 修订在新数字、新实体的保留题上是否仍然成立？
4. 同一表达配置中，高低 `intervention` 是否改变未被请求时的具体建议倾向，同时响应明确求助、尊重明确拒绝？

不同属性分别报告，输出长度和引擎派生stance不作为人格效果真值；一次调用不证明人格与事实判断获得硬隔离。

## 阶段与预算

研究硬上限800次请求，四线程并发，每个阶段顺序执行，不并发启动多个阶段进程。记录全部已分配单元，异常不替换、不请求重试；三次请求错误后停止发新请求，已在途请求可完成。固化有时不需要故事调用，因此请求上限不是必须消耗的数量。

如B1两个原始评价者平均的未请求建议率高低差不大于零，或明确拒绝组的平均建议率高于10%，允许按固定规则进行一次有针对性的策略修订，并在四个新场景追加至多96条行为输出。追加前固定新任务和版本，保留旧标签；否则不追加。所有阶段合计仍不得超过800次。

## 格式对照与评分

六个格式族为金额结论、跨日时间、JSON标量字段、JSON筛选数组、计算表格、更正与未知表格。三个轮次各24个固定问题，问题全文两两无重复；用明确的文字要求，不用容易被当作XML的尖括号占位。两种表达配置为同一服务模型上的蓝鱼和白龙参考配置。

R1/R2三臂分别是归档基线、修订实现但不传契约、修订实现并传显式契约。保留无契约臂用于识别普通源码改动和契约编译提示的差别。所有臂使用同一个问题、人设与底层接口；契约没有金标答案。机械validator不改变已生成文本，不得将它本身解释为事实能力提升。

内容评分只覆盖可按固定规则提取的所问目标：结论行或最后独立答案、JSON指定值、表格指定单元格。格式与内容、覆盖与正确分别保存；JSON布尔与数字语义分开，要求的单位保留。主联合评分同时满足目标与格式，不评价全文全部断言。R2前的递归JSON评分补充及与旧标签的一致性见 [scoring_amendment.json](scoring_amendment.json)；不回写R0/R1原标签。

额外离线机制探针测：合法格式与已知破坏格式的误报/漏报、格式正确但事实错误仍能通过机械检查、低置信度合法更正、高置信度无来源猜测、撤销、错目标与跨主题操作。开发中暴露的新边界保留原探针及版本，再补充针对性验证，不伪称全部离线案例在R0前固定。

## 真实记忆工作流

每轮六个情景，各比较基线与该轮修订实现，每格一条独立工作流。R1使用19→23，R2使用11→31的新数字。每条流程为两轮旧偏好训练→真实固化→一轮更新/干扰→真实固化→载入实际记忆与空白记忆两个隔离新会话探针；最多五条输出、九次请求。

六情景是明确更改、自身旧偏好撤销且新值未定、一次临时例外、引用同事偏好、只是考虑尚未确认，以及含引用指令字符串的历史来源干扰。探针不接收原训练历史，不手工改写固化判断或置信度。保留真实候选、证据ID、用户完整原话、提议操作、生效/拒绝原因及账本重建结果。缺失探针与回答错误分开记录，但均保留计划分母。

## 改进与复验规则

基线在任何本轮代码编辑前归档。revision A在R1前冻结；只允许基于开发轮和离线机制结果做一次revision B，再冻结并执行R2。不可看R2输出后调整代码、任务或金标以改善该轮成绩。若没有充分修改依据，则R2沿用A；不同轮次不拼成代码优越性的随机试验。

人格参数不能自动成长，默认仍一次前台生成，记忆另行固化。固化在指定阶段显式执行，不测默认300秒定时器或真实跨日效果。机械约束与词面来源门控不证明模型语义解释正确。

## 行为测量与统计

行为评价规则见 [behavior_codebook.md](behavior_codebook.md)，在B1输出前固定。两次单独启动的Codex任务分别标具体行动建议、替用户决定/施压、澄清提问、尊重拒绝；隐藏参数和条件标签，用户提问本身仍暴露请求边界。保留两套标签，分别统计并报告一致率/κ，不伪称独立人类评审。

格式对比按六个格式族聚类，记忆按六情景配对，行为按六场景及重复平均后比较；用4000次配对bootstrap给描述区间。逐输出Wilson区间仅作描述，不消除共享任务、服务、缓存与时间依赖。不做确认性显著、等效性、普遍安全或人格体验断言。

请求模型deepseek-chat、温度0.7、最大输出2000 tokens、超时120秒，保存实际响应模型、用量、完成原因及耗时。本地随机种子不是远端采样seed。所有输入为合成材料，认证信息只存在于进程环境。
