怎么读

六段彼此独立的对话。你是坐在旁边的听者，不需要读过故事，也不用猜角色应该怎么说。

先读六段，用自己的话说听到了什么，或直接选“听不出来”。随后再各用一遍，判断人物的打算和可能的理由。每次点“保存并继续”后，该答案即锁定；刷新可以从上次保存处继续。

这里没有答对提示。如果以前看过这一段、或已经知道角色当时的私人设定，请在那一题勾选“此前知道”。
