# 听者能从哪句话里知道角色的私事？

本轮只复用[固定经历归属对照](../reference_growth/paper.md)已交付的回复。问题是：不知道角色私情的听者，能否辨认角色当下想做什么，以及这么做的私人缘由？不把是否喜欢这句话或角色是否健谈列入计分。

**来源与分卷。** 以两位角色的成长（G）、冻结（F）及同输入独立冻结复采（S）为主比较。六个情境、三个分支、两次重复、两个角色，共 72 条；只用于拆解提示的 24 条不进入本研究。不以先前得分、长度或协议是否完整选例。预先固定 12 份卷，每份六条、六个不同情境，每个角色的三个分支各一条。十二卷合起来恰好覆盖全部 72 条。每名听者只做一份，不通过让同一人重做凑人数。第一份避开此前在对话中直接解说过的唐荔留言簿、唐荔看台两个人物情境；其余熟悉的题由听者自行标记。后续评审依卷序分配，不视为已经招募。

**呈现。** 第一遍只显示公开场景、搭档原话和实际回复。听者可以写自己听出了什么，也可以直接点“听不出来”；不提供候选。本遍全部锁定后才展示两种当下打算；打算也全部锁定后才展示两种可能的私人缘由。每项都可选“仅凭这句分不出来”或“两项都不符，我听出的是别的”。作出确定判断时，从角色回复中指出一小段依据。没有答案反馈，页面不下发真值、分支、先前评分、其他阶段选项或角色的私人说明。所有题里的两种可能都是书面材料；仅其中一种与原设定相符，并非每条回复都真的让人听得出来。

**预先确定的读法。** 自由读法、当下打算和具体缘由分开。选择与设定相符、选择了另一个解释、主动弃判、听出别的意思、缺答五种情况分列；“听不出来”是有效观察，不当成错误或缺失。引文须在台词中原样出现，命中设定本身不证明引文支持推断。第一遍的原话保留供解盲前核对，不从后续选择倒填。主表只含完卷听者未标记熟悉的题；另列协议完整子集、熟悉题和不完整卷。按角色与分支汇总，保留每项分母；G 分别与 F、S 比较，后两者也要相互比较。第一位听者每个角色每个分支至多一条，且场景不同，只能形成个案，不能估计成长优势。只要十二卷没有收齐，不作覆盖所有材料的判断；即使收齐，仍需区分题目、听者和角色，不把 72 条当成 72 位独立听者。

**复现与保管。** `python listener.py check` 验证分卷、素材和选项位置；`python listener.py serve` 启动本机第一卷，返回实际网址；`python listener.py report` 读取本地提交并输出计数。后续独立听者用 `--form 2` 等指定卷号。文件指纹见 [registration.json](registration.json)。真人原话与答卷默认只保存在仓库忽略的本机 `data/`，不随研究材料发布；无需 API 密钥。这里是采集前方案，真人结果只能来自实际提交。
