# 强化提示的完整流程确认

在固定状态配对探针之后新增本阶段：强化提示在共同状态中36/36符合预期，但尚不能证明交互轨迹恢复。每个3任务×2偏好组合仅重复一条六轮流程，共6流程36次请求；使用相同冻结实现、用户模拟器和强化提示。单次不重试，累计3次服务异常停止；无论结果如何不继续追加同批试验。

本阶段单独保存，原主研究和配对探针不改，原各阶段额度不变。新增36请求后，全研究请求上限为180。这是对观察到的修订所做确认，不是预先保留的新实例检验。

衡量执行接受数、已确认答案/拒答/未知、任务可完成数、与程序原流程的可见交互是否逐字相同。不给新输出沿用旧标签，不新增人类体验主张。若输出相同，只报告相同这一事实。
