# 固定共同状态下的配对决策补测

研究动机：主研究出现冷却期提议被拒收后的连续失败。为区分单次状态理解和交互反馈，同时比较提示说明，取主研究程序策略的36个完整payload，固定状态，不执行新对话。

每个payload分别请求原提示和冷却说明更明确的提示各1次，共72次决策探针，单次不重试。两种提示仅说明粒度不同，原规则不变；都不得看到程序预期id或eligible_ids。顺序预先随机化，temperature=0.3,max_tokens=128，同一服务标识。最多72次请求，累计3次服务异常停止。

评价程序规则下的合法提议和预期id匹配。null始终是合法主动不问提议，预期匹配另衡量主动性与优先顺序。统计36个配对结果、冷却子集及原始请求；不计为72条完整用户回复，不做独立用户或一般统计显著性推断。该补测不是主研究的重试，主研究失败与汇总保持不变。总研究请求上限144。
