## 阅读研究

[研究资料与复现](research.md)按版本汇总论文、原始实验数据、定量图表与复现入口，区分初步研究、重复对照和框架修订验证。

核心约定是默认 `text` 在一次前台调用中产生 `HEAD → SAY → TAIL`，后台记忆异步提炼。人格影响关注点、站位、行动选择和表达取舍；内部建议不要求全部外显。事实、计算和证据标准保持不变。自动人格成长尚未接入可靠策略，模型记录与本地有效标记均不作为独立真值。
