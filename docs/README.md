## 阅读研究

[本期阶段论文：人格工程怎样记住经历](validation/synthesis_2026_11_12/paper.md)汇总角色体验、慢成长、关系记忆与知情边界。五张结果表保留各自分母，可从同目录的公开数据离线复算。

[人格表达评价](evaluation.md)区分人格、情境、事实逻辑和明确边界；正式或机械感是风格描述，不作为通用自然度硬门槛。

[研究资料与复现](research.md)按版本汇总论文、原始实验数据、定量图表与复现入口，包括初步研究、重复对照、框架修订、多轮机制及共享资料下的强传统提示比较。

核心约定是默认 `text` 在一次前台调用中产生 `HEAD → SAY → TAIL`，后台记忆异步提炼。人格影响关注点、站位、行动选择和表达取舍；内部建议不要求全部外显。事实、计算和证据标准保持不变。自动人格成长尚未接入可靠策略，模型记录与本地有效标记均不作为独立真值。
