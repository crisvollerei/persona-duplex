# 怎样评价人格表达

[文档导航](README.md) · [研究与数据](research.md)

人格表达的目标是符合既定人格、当前情境与事实逻辑。评价不以“像普通人聊天”作为统一标准：克制、正式、略显机械的表达可以符合守岸人的设定；活泼、俏皮的表达也可以符合另一种人格。风格不同本身不是质量差异。

## 分开评价四个问题

| 维度 | 核心问题 | 不能用来替代它的指标 |
| --- | --- | --- |
| 人格符合度 | 实际语气、注意和互动取舍是否符合提供的人格规范，以及规范允许的情境变化？ | 人设名字、口头禅数量、参数命中率、模型自报标签 |
| 情境适切性 | 是否接住用户实际表达的内容、完成必要请求，展开或留白是否合适？ | 越长越好、建议越多越好、越口语越好 |
| 事实与逻辑 | 已知事实、计算、条件与不确定性是否得到保留？ | 协议有效、内部检查器说“一致”、人格分高 |
| 明确边界 | 是否尊重用户实际表达的禁问、禁建议等要求？ | 语气礼貌、出于关心、人物主动性高 |

前两维可用有锚点的等级量表，后两维按有证据的支持、违规或未知分别记录。信息不足保留未知；不把未知默认算正确。事实或边界错误不能通过其他高分抵消。

## 风格与问题的区别

“正式”“机械”“活泼”“口语”“有意象”作为描述，不自动加减分，也不构成筛选门槛。通用自然度若在历史研究中出现，只能在对应量表的定义下解释，不能直接等同人格效果或真实用户偏好。

人格允许的意象、比喻和角色陪伴语句不应机械地作为现实断言判错。例如“我在这里”可以是角色中的陪伴表达。但角色设定不授予定位用户、访问外部系统、执行事务或保证未来结果的能力。正式句式不能豁免答非所问，活泼语气不能掩盖无依据的具体事实或心理断言。

人格是倾向，不是每一轮都要完成的配额。平时安静的角色在明确问答中应回答必要内容，活泼角色在禁问情境中可以留白。人格符合度应包含这种合理变化，不能简单等于程序选择器与目标整数的距离。

## 评审与报告

评审人格时必须提供目标人格规范及完整必要语境，同时隐藏生成方法、自报标签、是否被选中和其他评审结果。评分要能定位实际回复、人格规则及情境证据。同一句话配不同目标人格是不同评审项，不能跨人格复用评分。

模型评审、人工评审与真实用户体验分别报告；两个同类模型评审任务不构成两个独立人类意见。保留分歧，避免事后合成唯一真值。手写校准项只能检查量表是否区分预设问题，不代替真实分布的有效性验证。

程序行为记录、模型语义标签、实际交付文本、人格评价和事实判断应分开。研究需要报告每项分母、未知和缺失、完整成本及明确限制，不用一个综合通过率掩盖取舍。更换评价构念应建立新版本，保留历史材料和原结论。

## 与强提示比较“不弱于”

没有显著差异不等于已经证明不弱于。比较前应固定适用场景、主要维度、可接受的退步界值与不确定性判定；界值是研究假设，不能在看到结果后调整。人格和情境分别检验，各人格与各评审单列，不能让一个角色的收益抵消另一个角色的退步。事实、明确边界和请求履行另外报告，未知与缺失不得默认为正确。

强提示应在独立开发材料上认真优化，并获得相同人格语义、事实、相关历史及合理检索资料。冻结候选选择后才运行新测试情境；同时报告两路实际调用、token与等待，不能把更高计算投入隐藏在同样“一次调用”中。少样本不能排除稀有失效：零观测也应给出非零风险上界。

[非劣性先导研究](validation/noninferiority_pilot_2026_11_10/README.md)给出一版具体操作标准；其0.30分界值是该研究的作者工程阈值，不是所有人格或用户通用的容忍标准。先导样本的通过、证据不足及需要收窄范围分别解释，不按结果自动追加同批样本。

可复核的操作性量表、校准材料和小规模验证见[人格条件化评价研究](validation/persona_evaluation_2026_11_07/README.md)。该实验独立运行，不改变默认前台单次生成或增加默认评审调用。
